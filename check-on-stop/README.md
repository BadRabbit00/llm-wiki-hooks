# check-on-stop — главный гейт

Событие: **Stop** (агент собирается завершить ход).
Команда: `wk hook check`.
Поведение: проверки не прошли → код 2, ход не завершается, причина уходит агенту.

Закрывает весь набор правил, которые иначе висят просьбами в `AGENTS.md`: забытый статус,
маркер без факта, факт без маркера, битая ссылка на ID, устаревший блок политик, бюджет строк.

## Почему `wk hook check`, а не `wk check --strict`

Блокирует **только код 2**. Любой другой ненулевой код оба харнесса трактуют как
«неблокирующая ошибка»: ход завершается, stderr уходит человеку, а не модели.
А `wk check --strict` возвращает 1 при найденных ошибках и 3 при недоступной сети —
то есть поставленный хуком напрямую он не блокирует ничего и работает украшением.

Обёртка отображает коды так:

| состояние | `wk check --strict` | `wk hook check` |
|---|---|---|
| чисто | 0 | 0 |
| ошибки или предупреждения при `--strict` | 1 | **2** |
| сеть недоступна | 3 | 0 + предупреждение в stderr |
| нет манифеста | 3 | 0 |

Офлайн не блокирует намеренно: ход, который агент не может завершить и не может починить, —
это не защита, а тупик. Непробиваемость в этом случае обеспечивает CI.

## `stop_hook_active`

В payload `Stop` приходит `stop_hook_active: true`, если ход уже продолжен по решению
предыдущего хука остановки. При этом значении `wk hook check` возвращает 0 без проверок.
Иначе неисправимая ошибка даёт бесконечный цикл «блокировка → попытка завершить → блокировка».

## Блокировка у codex

`Stop` в claude-code числится блокирующим событием прямо в документации. Для codex
таблица блокирующих событий не опубликована, поэтому там гейт **дублируется в CI**
тем же `wk check --strict` — это не замена, а страховка.

## Бюджет

`timeout` 10 секунд: проверка `docs/` локальная, но свежесть блока политик требует запроса
к вике (`wk check` вызывает `/policies/compile`). HTTP-таймаут самого клиента — 10 секунд,
при его истечении команда даёт код 0.

## Состояние реализации

`wk check --strict` реализован (задачи 06 и 07A). Подкоманды `wk hook check` ещё нет —
её контракт — в `../../fix.md`, раздел A1. До реализации хук не включать:
`wk hook check` вернёт код 1 «неизвестная команда», что на `Stop` даёт шум без блокировки.
